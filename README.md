# 🚀 Jira to GitHub SDLC Automation Agent

## 📌 Overview
This project automates the Software Development Life Cycle (SDLC) by integrating Jira and GitHub.

It fetches Jira tickets, creates branches, commits code, and automatically generates pull requests.

---

## 🛠️ Tech Stack
- Python
- Git & GitHub
- Jira API
- REST APIs
- DevOps Practices

---

## ⚙️ Features
- Fetch Jira ticket details
- Create feature branch automatically
- Commit and push changes
- Generate Pull Requests

---

## 🔐 Security
- Uses environment variables
- Follows least privilege principle
- `.env` excluded using `.gitignore`

---

## 🚀 How to Run

pip install requests python-dotenv  
python .github/skills/my-new-skill/scripts/process_data.py
